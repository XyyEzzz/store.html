# This file is a complete web-based café ordering application developed using HTML, CSS, and vanilla JavaScript. It provides an interactive ordering interface featuring a modern dark-themed design, smooth animations, accordion-style product menus, toast notifications, sound effects, and a responsive layout. The source code is organized into clearly defined sections, including styling, configuration, data management, event handling, shopping cart functionality, and WhatsApp integration, making the project easier to understand and maintain.

# The application adopts a data-driven approach by storing all product information in a centralized data structure named masterMenu. Each product category contains multiple variants, prices, and optional size or additional topping selections. During initialization, the application dynamically generates the entire menu based on this data, eliminating the need to manually create individual HTML elements for each product. This design makes the system highly scalable, as new menu items or categories can be added simply by modifying the data structure.

# The ordering system includes a fully functional shopping cart that allows users to add products, automatically increase the quantity of duplicate items, remove items, and calculate the total price in real time. Every change is immediately reflected in the cart, while visual animations and audio feedback enhance the overall user experience. The checkout process also provides visual confirmation through transition effects before completing the transaction.

# An additional feature of the application is a hidden administrator panel that can be accessed after clicking the project title a predefined number of times. Through this panel, administrators can enable or disable product availability by marking items as sold out or available. The stock configuration is stored in the browser's local storage, ensuring that product availability remains consistent even after the page is refreshed or reopened. Disabled products automatically become unavailable for customers to purchase.

# The checkout feature is integrated with WhatsApp to simplify the ordering process. When customers confirm their orders, the application automatically generates a formatted message containing the selected products, quantities, total price, and a predefined motivational message. It then redirects the user to a WhatsApp conversation with the designated business number, where the generated order message is ready to be sent. After the redirection process, the shopping cart is cleared, allowing the application to be used for a new transaction.

# Overall, this project demonstrates a well-structured single-page web application that combines dynamic interface generation, client-side data management, local storage persistence, interactive user experience, and WhatsApp integration. Its modular architecture and data-driven design improve scalability, maintainability, and usability, making it a practical solution for a lightweight digital ordering system suitable for cafés, small businesses, or personal projects.
